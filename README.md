# Фонд оценочных средств по дисциплине «Разработка и развертывание клиент-серверных приложений с ML-компонентами»

Этот репозиторий предназначен для открытого и воспроизводимого представления фонда оценочных средств (ФОС) по дисциплине «Разработка и развертывание клиент-серверных приложений с ML-компонентами». Здесь объединены рабочая программа дисциплины, модель измерения результатов обучения, контрольно-измерительные материалы (КИМ), критерии оценивания, методические рекомендации и используемые образовательные ресурсы. Результаты обучения связываются с компетентностно-ролевой моделью в области искусственного интеллекта (КРМ версии 3.0).

## 1. О дисциплине

**Цель дисциплины.** Формирование у студентов комплексных знаний и практических навыков разработки веб-приложений, интегрирующих решения, разработанные с применением технологии искусственного интеллекта и машинного обучения.

**Основные задачи.**
1. Изучение основ веб-технологий и принципов клиент-серверного взаимодействия
2. Приобретение навыков эффективного проектирования архитектуры
3. Развитие навыков работы с механизмами обработки и визуализации данных
4. Формирование умения создавать интерфейсы для взаимодействия с ML-моделями в реальных индустриальных условиях

**Структура и содержание.** Дисциплина состоит из 4 модулей: "Backend", "Frontend", "Интеграция и развертывание", "Защита проекта". Обучение включает лекции / лабораторные работы / проект / самостоятельную работу и завершается дифференцированным зачетом.

**Пререквизиты и связи с другими дисциплинами.** 
| Предшествующая дисциплина |	Компетенция |	Индикатор и уровень на входе |
|--|--|--|
|Объектно-ориентированное программирование|PL-2, PL-3|средний|
|Обработка данных на Python|PL-1|базовый|
|Машинное обучение|ML-3, ML-4, ML-7, MF-4, BD-1, LC-5|базовый|
|MLOps&DevOps|LC-4|средний|
|Технологии тестирования программного обеспечения|PL-3|средний|
|Компьютерные сети|LC-5|базовый|

**Планируемые результаты обучения.** По завершении дисциплины обучающийся сможет:

1. разрабатывать серверное API на Python (FastAPI) для этапов работы с данными и моделями машинного обучения, включая централизованную обработку ошибок и документирование программных интерфейсов средствами OpenAPI;
2. реализовывать клиентский интерфейс для загрузки данных, выбора и применения модели, а также визуализации результатов;
3. согласовывать контракт REST API между клиентской и серверной частями и обеспечивать сквозной вызов модели из пользовательского интерфейса (в том числе с учётом политики CORS и обратного прокси);
4. настраивать и кастомизировать контейнерный контур развёртывания (Docker, Docker Compose, Nginx, переменные окружения, многостадийная сборка) и обеспечивать воспроизводимый запуск рабочей версии приложения;
5. представлять и защищать целостное клиент-серверное приложение с компонентом машинного обучения, обосновывая архитектурные и технологические решения.

Полное описание приведено в [РПД](docs/rpd.md).

**Целевые роли КРМ (версия 3.0).** Дисциплина ориентирована на формирование компетенций уровня **средний (С)** по индикаторам **PL-1.1**, **PL-1.2** и **LC-5.1** для ролей, связанных с разработкой прикладных решений на основе ИИ и обеспечением их промышленной интеграции и развёртывания в клиент-серверной архитектуре. Исходная книга КРМ: [`data/krm-v3.0.xlsx`](data/krm-v3.0.xlsx). Коды компетенций и индикаторов, используемые в модели измерения и РПД, сверены с формулировками КРМ 3.0 (2026-07-28).
