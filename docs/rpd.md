# Рабочая программа дисциплины

## 1. Общие сведения

| Поле | Значение |
|---|---|
| Название дисциплины | Разработка и развертывание клиент-серверных приложений с ML-компонентами |
| Образовательная программа | Искусственный интеллект и машинное обучение  |
| Уровень образования / формат ДПО | Бакалавриат |
| Объем | 108 ч. / 3 з.е. |
| Формат обучения | Очный |
| Форма промежуточной аттестации | Дифференцированный зачет |

## 2. Цель и задачи

**Цель:** Формирование у студентов комплексных знаний и практических навыков разработки веб-приложений, интегрирующих технологии искусственного интеллекта и машинного обучения.

**Задачи:**

1. Изучение основ веб-технологий и принципов клиент-серверного взаимодействия
2. Приобретение навыков эффективного проектирования архитектуры
3. Развитие навыков работы с механизмами обработки и визуализации данных
4. Формирование умения создавать интерфейсы для взаимодействия с ML-моделями в реальных индустриальных условиях

## 4. Планируемые результаты обучения

По завершении дисциплины обучающийся сможет:

1. разрабатывать серверное API на Python (FastAPI) для этапов работы с данными и моделями машинного обучения, включая централизованную обработку ошибок и документирование программных интерфейсов средствами OpenAPI;
2. реализовывать клиентский интерфейс для загрузки данных, выбора и применения модели, а также визуализации результатов;
3. согласовывать контракт REST API между клиентской и серверной частями и обеспечивать сквозной вызов модели из пользовательского интерфейса (в том числе с учётом политики CORS и обратного прокси);
4. настраивать и кастомизировать контейнерный контур развёртывания (Docker, Docker Compose, Nginx, переменные окружения, многостадийная сборка) и обеспечивать воспроизводимый запуск рабочей версии приложения;
5. представлять и защищать целостное клиент-серверное приложение с компонентом машинного обучения, обосновывая архитектурные и технологические решения.

Связь результатов с компетенциями КРМ, дескрипторами и контрольно-измерительными материалами приведена в модели измерения корневого [README](../README.md#2-модель-измерения).

## 6. Система оценки результатов обучения

Промежуточная аттестация включает проверку теоретических знаний, практических умений и навыков по всем разделам дисциплины, а также защиту индивидуального проекта.

| Сумма баллов | Оценка | Краткая характеристика |
|---|---|---|
| 225–250 | 5 (отлично) | Обучающийся в полном объеме освоил содержание дисциплины, уверенно выполняет практические задания и демонстрирует высокий уровень подготовки при защите проекта. |
| 175–224 | 4 (хорошо) | Обучающийся в целом освоил содержание дисциплины, допускает отдельные неточности, но показывает достаточный уровень знаний и умений. |
| 125–174 | 3 (удовлетворительно) | Обучающийся освоил основные положения дисциплины, однако допускает существенные недочеты в отдельных видах заданий и при защите проекта. |
| 0–124 | 2 (неудовлетворительно) | Обучающийся не продемонстрировал достаточного уровня освоения дисциплины, задания выполнены с существенными ошибками либо не выполнены в полном объеме. |

Детали приведены в разделе [Exam](../Exam/README.md)
