## Модуль 3: маршрут сдачи и пороги

Рекомендуемый порядок работ:

1. Эссе (после лекций 3.1–3.2) → [M3-integration-kim-essay.md](M3-integration-kim-essay.md)
2. Лабораторная работа 3.3 (интеграция с моделью из UI) → [M3-integration-kim-01-labrab.md](M3-integration-kim-01-labrab.md)
3. Лабораторная работа 3.4 (Docker Compose + Nginx) → [M3-integration-kim-02-labrab.md](M3-integration-kim-02-labrab.md)
4. Лабораторная работа 3.5 (Nginx + multi-stage) → [M3-integration-kim-03-labrab.md](M3-integration-kim-03-labrab.md)
5. Самостоятельная работа 3.6 (развёртывание **своего** проекта) → [M3-integration-kim-04-srs.md](M3-integration-kim-04-srs.md)

Итого по модулю — **50 баллов** (эссе 5 + ЛР 10+10+10 + СРС 15). Работа считается зачтённой при наборе не ниже порога:

| Работа | Макс. | Порог зачёта |
|---|---:|---:|
| Эссе | 5 | ≥3 |
| Каждая лабораторная работа (3.3–3.5) | 10 | ≥6 |
| Самостоятельная работа 3.6 | 15 | ≥9 |

Описания заданий и шкалы баллов приведены в файлах МУ и в каталоге [M3-integration-deployment](../../M3-integration-deployment/README.md).
